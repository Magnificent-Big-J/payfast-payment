# v2 Design Notes Superseded

This file is retained only to prevent old links from breaking.

The previous draft proposed migrations, Eloquent models, Laravel routes/controllers, and Vue/Vuetify components. That direction is superseded by the native v2 package plan:

- The package remains headless.
- The package owns PayFast protocol integration.
- Host applications own persistence, routes, controllers, UI, plans, invoices, authorization, webhook idempotency, and SaaS policy.
